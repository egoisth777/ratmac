# Wishlist

Unordered ideas with zero commitment. Promotion is a human decision.

- **Authorized review before every State change** — Billy, 2026-07-30. The working agent delivers but cannot approve its own transition. A reviewer group inspects the delivery, its designated Approver or team lead alone authorizes the transition decision, and the Engine verifies that authority before it writes the next State. Keep these semantic reviewer roles distinct from ratmac's mechanical `Guard`; signer identity, group membership, quorum, and authorization mechanism remain undecided. On promotion, this explicitly revisits the revocable adopted default in [machine composition's reviewer-independence requirement](issue/archive/i-018-machine-composition/spec.md#requirement-records) that signer identity remains outside the Engine. Selected 2026-09-22; carried by [authorized review transitions](issue/i-062-authorized-review-transitions/index.md).
- **Bind self-development completion to the selected issue** — Advisor, 2026-08-04. Evidence: archive tag `trial-archive/trial-002-doctor-full-fingerprint` and durable log `trials/trial-002-doctor-full-fingerprint/trial-log.md` record a Run that reached `passed` from agent-writable `artifacts/release.txt`, while fresh feature tests, candidate output, and independent review were checked only by the human driver. Desired end: a self-development Run can pass only when its guards bind the selected issue to fresh red/green receipts and independent review, so an unrelated writable marker cannot certify completion. A human still must choose the exact receipts, guard, and reviewer-authority contract. Selected 2026-09-22; carried by [selected issue completion](issue/i-042-selected-issue-completion/index.md).

- **A runbook node that runs a skill itself powered by a ratmac runbook composes safely: each level owns its own Engine root, the parent consumes only the child Run's terminal receipt as evidence, and runaway recursion (a skill chain that reaches itself again) refuses by name instead of looping** — Billy, 2026-08-09. Evidence: .arca/schema.md names a single Engine root `.ratmac/` and defines no behavior for a node whose command is itself a ratmac Run; no depth or lineage guard exists in the Engine today. Desired end: a nested ratmac-powered program is an ordinary black-box invocation with a receipt — no shared state across levels, and a cycle or depth overrun is refused with the offending lineage named. Selected 2026-09-22; carried by [safe nested invocations](issue/i-060-safe-nested-invocations/index.md).
- **One opt-in trace channel for the decisions a debugger cannot replay** - Billy, 2026-08-10. Evidence: the Engine is a short-lived command, so the interesting moments - which edge a transition input selected, why a guard refused, which lock was taken and in what order, what the mint record read and wrote, which root a path resolved through - leave no trace unless they happen to end up in a refusal message. There are 24 direct `eprintln!`/stderr writes scattered across `src/`, each authored for one call site, and a test that wants to see a mid-operation decision has to compile in a pause point (`test-fault-injection`) and stop the process. Desired end: one module owns a trace channel that is off unless a caller asks for it by environment variable, writes to stderr only, never to stdout and never to a file, and emits one structured record per decision with the stable diagnostic code the refusal path already uses. Constraints that make it safe rather than another global: no timestamps, durations, or absolute host paths in the output, so two runs of the same input print the same bytes; no runtime state and no allocation on the off path; nothing a guard or gate may ever read - the trace is for a person reading a failure, never evidence; and the existing stderr writes move into it instead of living beside it. Open before promotion: whether the channel replaces the compiled-in pause points or stays beside them, and whether hidden lanes may assert on trace text at all (they should not - that would make prose a contract again). Selected 2026-09-22; carried by [deterministic trace channel](issue/i-061-deterministic-trace-channel/index.md).
- **The cycle declares no human-authorized pause** - found by the `t-093` hidden lanes, filed 2026-08-10. A sprint that must stop for an out-of-scope reason has only `rtm abandon`, which retires the Run instead of pausing it. Wanted: one authorized pause route per stage that can legitimately wait, so a blocked sprint keeps its address and its evidence. Selected 2026-09-22; carried by [cycle pause routes](issue/i-050-cycle-pause-routes/index.md).
