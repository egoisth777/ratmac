# Wishlist

Unordered ideas with zero commitment. Promotion is a human decision.

- **Use State, not Phase, for machine position** — Billy, 2026-07-30. Replace the public `Phase` term and the Runbook's `phases` vocabulary with `State`; “Phase” suggests a linear process and misstates a general state machine. Before promotion, resolve the existing collision with `State File` and its lifecycle `status` field so “state” does not ambiguously mean the graph position, the persisted artifact, and the whole runtime record. This is a product-language and schema cutover, not a local code rename.
- **Authorized review before every State change** — Billy, 2026-07-30. The working agent delivers but cannot approve its own transition. A reviewer group inspects the delivery, its designated Approver or team lead alone authorizes the transition decision, and the Engine verifies that authority before it writes the next State. Keep these semantic reviewer roles distinct from ratmac's mechanical `Guard`; signer identity, group membership, quorum, and authorization mechanism remain undecided. On promotion, this explicitly revisits the revocable adopted default in [machine composition's reviewer-independence requirement](issue/deferred/i-018-machine-composition/spec.md#requirement-records) that signer identity remains outside the Engine.
- **Engine-namespace split** — Billy, 2026-08-03. Move the files the Engine owns or consumes — the runbook, the runs roster, the lock, the receipts — out of `.arca/` into an engine-named root, and make the arca folder roots the contract guards read (`issue|ticket|residual|goal`) runbook data instead of Rust literals, retiring the hard-coded-path debt (R-016). Why: one folder with two writers forces a per-file ownership ledger in the schema; one folder per owner replaces that ledger with a single structural rule, and a second project can adopt `rtm` without minting a folder named after a methodology it does not run. On promotion this rewrites frozen goal text (run layout in FDC-004, receipt paths, the runbook location) and steering identity, so it enters only through a planning pass; its one ordering fact is on the Horizon — land before the cycle-as-runbook issue (`i-015`), or the self-hosting runbook welds the old paths into the shop's own loop.
