# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| `EDN` | **Edition** - this issue's stable requirement-ID prefix. |
| Edition | A commit this shop has declared a stable base for developing the engine, marked by an annotated tag named `edition-NNN` whose message records what was proven there. Sequential, never moved, never deleted. |
| Cutting an edition | Creating that tag, at rest, after the gates are green. The act is what makes the claim; the tag is only where the claim is written down. |
| At rest | The cycle's own last stage: nothing pending in the intake work area, no open work item, no gap record left unproven. |
| Checkpoint | Unchanged and not an edition: the throwaway safety commit inside a ticket worktree that deliberate damage restores from (working rules, "damage only from a checkpoint"). Named here only so the two are never confused. |
