# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| Authoring check | A shape check a contributor can run on an issue that is still `pending`, before P1 folds it in. Distinct from the intake gate, which judges the P1 exit state. |
| Issue scaffold | One command that creates an issue folder with its five files, its identity already resolved, refusing on collision without writing anything. |
| Requirement prefix | The uppercase letter group starting a requirement ID, such as `PGE` in `PGE-001`. Each issue batch claims one that no goal requirement already uses. |
| Author field | A field the issue author can fill honestly at authoring time. |
| Integrator field | A field only P1 can fill, because it records a decision or an integration outcome: disposition, requirement ID, and the goal-file trace columns. |
