# Ubiquitous language
## Terms
| Term | Meaning |
| :--- | :--- |
| Pause marker | The file a pause point writes when its paused command reaches the boundary, at the path passed as a `RATMAC_TEST_*_MARKER` setting. |
| Boundary line | A pause marker's complete text: one line naming the boundary (or, for a lock hold, the held lock), ending in a newline. |

Existing project terms follow [the dictionary](../../dict.md) and [goal language](../../goal/ubi-lang.md).
