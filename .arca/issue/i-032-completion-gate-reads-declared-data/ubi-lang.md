# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| `CGD` | **Completion from Declared Data** - this issue's stable requirement-ID prefix. |
| Declaration | The three explicit lists selected by runbook data for focused, hidden, and quality checks. This workflow currently names its fields `focused-tests`, `hidden-lanes`, and `quality-commands`; those names are not Engine vocabulary. |
| Prose shape | Structure inferred from a document's rendering - headings, backticked tokens, id-looking strings - as opposed to declared fields. `CGD-003` requires the completion gate to infer nothing from it. |
| Opaque check id | A declared id or command the Engine matches verbatim against receipts, carrying no grammar the Engine understands. |
