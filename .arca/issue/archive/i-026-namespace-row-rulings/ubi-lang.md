# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| `NRR` | **Namespace row rulings** — this issue's stable requirement-ID prefix. |
| Held fact | The record that a ticket is paused for an out-of-scope reason, together with what it is waiting on. Today it is stored by rewriting the contributor's ticket file. |
| Named exception | A single spelling of a retired folder name, declared once in Engine source under its own name and pinned by a check that fails on a second one or on a rename. |
