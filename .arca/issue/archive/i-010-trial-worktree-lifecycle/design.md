# Issue design

## Proposed mechanics

Suggested design only — the binding requirements live in [spec.md](spec.md); none of the mechanism choices below carry weight until folded into the goal.

- Interface: one PowerShell 7 script `tools/trial.ps1` with verbs `start`, `status`, `finish`, `sync`, invoked as `pwsh -File tools/trial.ps1 <verb> ...` from the repository root; plain Git commands and built-in cmdlets only — no modules, no network, no global state. Exit 0 on success; non-zero refusals print one named reason plus guidance on stderr. `status` is the dry-run: every mutating verb computes a plan first, and `status` prints those plans (planned mutations plus recovery commands) without applying them; `-Base` defaults to `exp/ratmac-deterministic`.
- Start: preflight (current branch equals the base, `git status --porcelain` empty, no collision across `refs/heads/trial-*`, archive tags, registered worktrees, the derived sibling directory, and `trials/*/`), then a single `git worktree add -b trial-<nnn>-<slug> <sibling-path> <base>` so partial states are minimized, then post-verification. On partial failure, remove only the newly registered worktree without force, then compare-and-delete the new branch ref only if it still points at the recorded base commit; do not prune unrelated registrations. If rollback itself fails, print exact state-specific manual recovery commands instead of retrying destructively.
- Identity derivation: trial number = max over `refs/heads/trial-*`, `refs/tags/trial-archive/*`, and `trials/trial-*/` directory names, plus one, zero-padded to three digits (wider numbers keep their natural width); `-TrialNo` overrides after the same collision scan. Worktree path = `<repo-parent>/<repo-basename>-<trial-branch>` (for example `../ratmac-trial-001-guard-timing`). Archive tag = `trial-archive/<trial-branch>`, annotated, message carrying base and terminal commits plus verdict line.
- Trial log: `trial-log.md` at the trial worktree root, from a template with fixed headings — Identity, Base and trial commits, Hypothesis, Procedure, Commands and tests, Observations, Verdict, Recommendations, Artifact and diff references. Validation is pure-read: every heading present with non-empty body, branch name matches the worktree's branch, recorded base commit is an ancestor of the terminal commit, recorded terminal commit equals the trial tip.
- Finish sequence: preflights (invoked from the primary repository checkout with the base checked out clean; own working directory not inside the trial worktree; trial worktree clean; log committed and valid), then strictly: create and verify the annotated archive tag at the trial tip (refuse if a same-named tag targets another commit); copy the log to `trials/<trial-branch>/trial-log.md` and commit it on the base as a single-file change (`trial(<trial-branch>): archive durable log`); `git worktree remove <sibling-path>` with no `--force`; then compare-and-delete `refs/heads/<trial-branch>` with `git update-ref -d` only if the branch still points at the recorded terminal commit and the verified tag still preserves that commit. Status recognizes tag-only, tag-plus-log, and worktree-removed intermediate states so an interrupted finish resumes from the first incomplete step without moving or duplicating durable artifacts.
- Windows lock handling: before removal, detect the trivial self-lock (script working directory inside the worktree) and refuse with a `cd` hint; when `git worktree remove` fails with the directory in use, print which sibling path is held and suggest closing shells/editors rooted there — no `Remove-Item -Force`, no process enumeration or kill.
- Sync: preflight clean base checkout, then plain `git merge main`; on conflict, exit non-zero listing conflicted files and leave the in-progress merge visible — no `--abort`, no `reset`, no `rebase`, no force flags anywhere in the script.
- Guidance wiring: `.arca/index.md` gains a short contributor note naming the interface entry point, the ownership split (human or Main-Agent run lifecycle verbs from the primary repository checkout with the experiment base checked out; the Advisor authors `trial-log.md`; Subagents invoke neither lifecycle verbs nor `rtm`), and the Windows working-directory rule; `AGENTS.md` stays the existing one-line pointer.
- Test wiring: QA fixtures (`cargo test -p ratmac-qa`) build throwaway repositories under a temp directory, shell out to `pwsh -File tools/trial.ps1`, and assert ref/worktree/tag snapshots around every positive and negative case; the deterministic lock fixture holds an open handle (a child `pwsh` with its working directory inside the trial worktree, or an open `FileStream`) to reproduce the Windows lock; the one non-fixture check is the read-only `status` smoke in this checkout.

This file is incoming evidence. Integrated mechanics remain authoritative only in the accepted forward authority.
