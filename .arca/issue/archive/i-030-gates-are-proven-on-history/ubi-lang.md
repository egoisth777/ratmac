# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| `GPH` | **Gates proven on history** - this issue's stable requirement-ID prefix. |
| Fixture with a past | A fixture repository that carries at least one artifact from an earlier point in its own story: an archived gap record citing an older freeze, an archived ticket, a retired Run, or a goal revision that has moved since a record was judged. |
| Fresh fixture | A fixture repository born at the current freeze, whose every record was written by the fixture itself moments ago. All contract-gate fixtures before this issue are fresh. |
| Contract gate | Any guard whose verdict rests on repository contents rather than on a single command's exit: today the intake contract, the record contract, the completion gate, and the sensitivity-receipt gate. |
