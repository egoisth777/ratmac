## Acceptance criteria

- Contract gates over fixtures: for each phase gate there is at least one executable fixture that passes with a correct artifact set and at least one negative fixture — status claims without integration, satisfied-without-evidence, cyclic ticket dependencies, prose-only P4 claims, receiptless P5 relabeling — that is refused with the offending artifact or missing receipt named.
- Sensitivity is executable: a fixture with a real planned test and a recorded baseline-failure receipt passes the P4-equivalent gate; the identical fixture with the receipt replaced by a matching prose log line is refused.
- Ownership audit: an executable check proves no active Phase Prompt or gate contract instructs writing `.arca/state.toml`, `.arca/log.md`, or `.arca/rtm.lock` directly, and the agent-writable evidence location is documented and distinct from Scheduler-owned files.
- Blocked route round-trip: in a fixture Run, a human `held` marking with a linked blocker record lets the Run route onward while the ticket stays not-passed and its residuals stay unproven; the same request without human authorization or without a blocker link is refused; Scheduler-owned bytes are unchanged across refusals.
- Run abandonment round-trip: in a fixture Run holding a broken active Run, an explicitly human-authorized abandonment makes RTM record a terminal abandoned event or equivalent evidence and retire the admission state and lock, after which a fresh Run start in the same fixture succeeds, with Scheduler-owned files mutated only through `rtm`; the identical request without human authorization is refused atomically with state, log, and lock byte-identical; a stale lock present at abandonment is retired by the authorized path, never bypassed.
- For gap analysis on this branch, the absence of a mechanized gate satisfying a requirement classifies that requirement `missing`; vacuous satisfaction is not available.
- All proofs run in isolated fixture projects through the QA harness; acceptance requires no commit, push, deployment, or global installation.
