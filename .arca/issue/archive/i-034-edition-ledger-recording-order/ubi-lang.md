# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| Edition ledger recording (`ELR`) | This issue's stable requirement-ID prefix: the corrected order in which an edition's ledger row is written - after the tagged commit exists, never inside it. |
| Recording landing | The landing immediately after an edition is tagged, whose whole job is appending that edition's ledger row citing the tagged commit's full hash. The row is immutable from then on. |
