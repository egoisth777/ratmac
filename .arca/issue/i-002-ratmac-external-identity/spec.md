- GitHub reports `egoisth777/ratmac` as the repository identity through both the API and `gh repo view`; the old slug is not the canonical identity.

- The issue artifact itself contains exactly five populated files, all front-matter/routes resolve, and no GitHub rename, filesystem move, origin mutation, implementation, push, deploy, or integration is performed while creating it.
