# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| Item record | The work item's file under the runbook's declared ticket root, named by the bound turn's `item` binding; the validator reads its list of gap record ids from it. |
| Unreadable record | A record file that exists, so the validator's existence test passes, but cannot be opened or read. For example, another program holds it open with no sharing, or its read permission was removed. |

Existing project terms follow [the dictionary](../../dict.md) and [goal language](../../goal/ubi-lang.md).
