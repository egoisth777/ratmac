# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| Partial folder | The hidden sibling folder, `.<name>.rtm-skill-partial`, that `rtm skill` fills completely before one move puts it at the requested path. |
| Brief file hold | Another program keeping a just-written file open for a moment, as a virus scanner or search indexer may. On Windows this can make moving the folder that holds the file fail. |

Existing project terms follow [the dictionary](../../dict.md) and [goal language](../../goal/ubi-lang.md).
