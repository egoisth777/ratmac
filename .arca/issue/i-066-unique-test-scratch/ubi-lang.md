# Ubiquitous language
## Terms
| Term | Meaning |
| :--- | :--- |
| Scratch folder | A folder a test makes under the system temporary folder to hold its own fixture project or files while it runs. |
| Clock tick | The smallest step by which the system clock advances; on Windows it is 100 nanoseconds, so two requests made in one tick read the same time. |

Existing project terms follow [the dictionary](../../dict.md) and [goal language](../../goal/ubi-lang.md).
