# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| `CGD` | **Completion from Declared Data** - this issue's stable requirement-ID prefix. |
| Declaration | The three front-matter list fields on a work item - focused tests, hidden lanes, quality commands - that alone define what completion must prove. |
| Prose shape | Structure inferred from a document's rendering - headings, backticked tokens, id-looking strings - as opposed to declared fields. After this issue the Engine reads none of it. |
| Opaque check id | A declared id or command the Engine matches verbatim against receipts, carrying no grammar the Engine understands. |
