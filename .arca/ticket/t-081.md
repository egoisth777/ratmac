# Ticket: t-081 — The Run Record is run.toml with a state field

## Vertical Outcome

A started Run writes one file, `.ratmac/runs/<run-id>/run.toml`, and the field naming
where that Run sits in its graph is `state`. Nothing else about the record moves: it still
carries exactly seven fields, still parses strictly and refuses a corrupt or short record
by the same words, still replaces itself atomically, and still has the Scheduler as its
only writer. No file is created at the pre-cutover name.

## Worktree Scope

- **Included:** the record's path and field name and every site that joins or reads them
  (`src/model.rs` per-Run path set, `src/state.rs` strict field list and store,
  `src/scheduler.rs`, `src/blocked.rs`, `src/abandon.rs`, `src/completion.rs`,
  `src/receipt.rs`, `src/ownership.rs`, `src/doctor.rs`), and the fixtures that plant or
  assert a record under `test/qa/`. Public coverage in
  `test/qa/tests/t081_run_record.rs`; six private lane checks.
- **Excluded:** refusing a record that still carries the pre-cutover name or field
  (`t-082`), report wording (`t-083`), and the runbook format (`t-080`, already landed).
  No field is added, removed, reordered, or re-typed; the lock file, the transition log,
  and the receipts keep their names and places.
- **Cross-Feature:** parallel sibling Runs keep writing collision-free records under their
  own run ids, and a linked worktree still resolves runtime through the shared Engine root.

## Merge Gate

- **Dependencies:** `t-080` is green and merged.
- **Ticket tests:** `SVCV-004` reds first against current source, which writes the
  pre-cutover filename and field.
- **Inherited red:** `t055_runbook_spec::ownership_paths_match_canonical_run_residency`
  is red at the freeze because the ownership rules already name the settled path; it turns
  green here and must be green at closure.
- **Hidden manifest:** `HT-081-01` through `HT-081-06` cover all six required lanes.
- **Quality and closure:** affected suites plus workspace quality gates pass, taken with
  `cargo test -p ratmac-qa` until [i-027](../issue/archive/i-027-duplicate-engine-binary/index.md)
  lands; `landed-commit` stays empty until the green ticket landing is merged.
