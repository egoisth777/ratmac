# Ticket: t-077 — Pre-split residue refusal

## Vertical Outcome

A live pre-split Engine artifact is never silently adopted or migrated. Each entry point
refuses with repair instructions when it encounters `.arca/ratmac.toml`, `.arca/runs/`,
`.arca/rtm.lock`, or flat `.arca/state.toml`, and it leaves the project byte-identical.
Archived receipts under `.arca/evidence/` are historical evidence rather than residue and
remain inert.

## Worktree Scope

- **Included:** a shared preflight that detects each live pre-split artifact before an
  Engine read or write; application to all Engine entry points and existing-Run routes;
  actionable refusal text; byte-preserving no-migration behavior; explicit inert treatment
  for archived `.arca/evidence/`; QA coverage in `test/qa/tests/t077_presplit_residue.rs`;
  and six private lane checks.
- **Excluded:** relocating runtime artifacts (`t-071`), defining root names (`t-076`),
  import or migration tooling, and changing hash-only pin semantics beyond applying its
  existing refuse-and-instruct posture to the new residue class.
- **Expected merge/output:** every listed artifact alone makes every Engine entry point
  refuse before it opens or changes runtime state; a clean `.ratmac/` project continues to
  run, and historical `.arca/evidence/` alone neither blocks it nor becomes Engine runtime.
- **Superseded-test fate:** the former FDC-005 flat-state-only residue coverage expands to
  four pre-split live artifacts and all entry points; its no-mutation and explicit-instruction
  oracle remains, while archived evidence gets an explicit non-residue control.
