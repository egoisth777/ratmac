# Ticket: t-055 — One typed parser: guards retained, kinds closed, absence refused

## Vertical Outcome

`MachineClass` is the only reader of runbook TOML. Guard kinds are a closed `GuardKind` enum whose variants carry their own typed fields, so an unknown kind and a field foreign to a kind are both parse errors naming kind, field, and location. Every authored guard survives the parse in declaration order, and the Scheduler evaluates, renders, and lists guards from that typed value. An absent or unreadable `.arca/ratmac.toml` refuses by name instead of yielding an empty machine.

## Worktree Scope

- **Included:** `src/machine.rs` (typed class, `GuardKind`, per-kind validation), `src/scheduler.rs` (consume the typed class in guard evaluation, prompt rendering, and pending-guard listing; drop the `NotFound` default arm), the strengthened vocabulary agreement check from t-054.
- **Excluded:** doctor surfaces (t-056), scaffolding and authoring guidance (t-057). Decided behavior does not move: this is a refactor plus one named refusal.
- **Expected merge/output:** one reader in `src/`, guards on the class, three lost `toml::Value` walks, and an absent runbook that says so.
