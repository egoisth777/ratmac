# Ticket: t-145 — live run pin check

## Vertical Outcome

The project-local bootstrap (`tools/rtm.ps1`), run from the primary checkout or a linked worktree, checks the Engine it resolves against the pin of every live Run in the one shared Engine root, and never reads the flat `.ratmac/evidence.toml`. After the `Engine:` and `sha256:` lines it prints one `Pin:` line per live Run, in Run-id order, saying that the resolved Engine matches that Run's pin, that the Run pinned another file, or that the Run has no readable pin; with no live Run, its one `Pin:` line says so. Its only pin refusal comes when the resolved Engine is a live Run's pinned file and no longer has that pin's hash: `bootstrap refused:` on standard error, exit code 1, and no `Engine:` or `Pin:` line, naming each such Run with its pin file, the observed and expected path and hash, and the full command that retires the Run. It writes nothing. This supersedes the recorded-pin clauses of the project-local bootstrap requirement (`ORS-002`) and the channel requirement (`ECP-002`).

## Worktree Scope

Implement only [the accepted live Run pin check issue](../issue/i-074-live-run-pin-check/spec.md).
Existing source boundaries: `tools/rtm.ps1` (how it finds the shared Engine root, reads live Run pins, prints the `Pin:` lines, and refuses, and its own description of its pin check) and `test/qa/tests/t045_bootstrap_doctor.rs`. The accepted mechanics name that suite's regression adjustments: the changed-pinned-file check (`LRPV-001`) replaces the flat pin of `fn bootstrap_refuses_pin_mismatch` with a live Run that the planted Engine starts in a fixture whose runbook has a second State, superseding the bootstrap's former pin-mismatch check (`ORSV-006`), and `fn bootstrap_resolves_offline` expects `Pin: no live Run in` instead of "no pin recorded". If the Cargo-built bootstrap checks (`SVEV-004`, `SVEV-005`) still record their pins in the flat `.ratmac/evidence.toml` when this ticket starts, their pins move to a live Run's pin here, citing this requirement, and every other assertion of theirs stays.
