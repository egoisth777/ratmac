# Ticket: t-140 — run-private freeze and ports folders

## Vertical Outcome

The freeze build folder (`ratmac-freeze-<commit>` under the system temp folder) and the pre-split ports sweep folder (`target/lanes`) stop being shared. Every test that builds the freeze tree extracts it afresh and builds it in a folder only its own run uses, which its caller takes from the locked-folder helper of the lane-folder requirement (SVE-007): a private lane passes its lane folder, and a public suite passes a folder named after the suite in its own `CARGO_TARGET_TMPDIR`. The freeze Engine is found through the reported-executable function of the build-message requirement (SVE-001) and is still built once per test process. The pre-split ports lane (`t-109`) sweeps its copied crates, and the pre-split ports suite runs the pre-split crates in place, each into a folder of its own from the same helper. No run reads or rewrites the old shared paths: a plain file at the freeze folder's old name changes no verdict, and `target/lanes` keeps every path and byte; nothing removes or migrates the old folders, runs simply stop using them.
