# Ticket: t-052 — Trial lifecycle: merge-only sync, interface audit, ownership guidance

## Vertical Outcome

`sync` merges `main` into a clean experiment base and nothing else — no reset, rebase, abort, or force — leaving conflicts visible; the interface exposes exactly start, status, finish, and sync offline; and contributor guidance states the ownership split and the Windows working-directory rule, which finish enforces.

## Worktree Scope

- **Included:** the sync verb, the executable interface audit, and the `.arca/index.md` contributor note.
- **Excluded:** start, finish, and log validation (t-050, t-051).
- **Expected merge/output:** a closed, offline, auditable verb set with documented ownership.
