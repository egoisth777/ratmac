# Ticket: t-086 — One command proves the suite

## Vertical Outcome

A test launches the build it was compiled against, always. The test package's copy of the
Engine command stops writing over the shipped one: it gets its own target name, every test
names that target, and a whole-repository build prints no output filename collision. The
shipped command is untouched — still `rtm`, still built from `src/bin/rtm.rs` without the
test-only pause points, still one path and one hash to the bootstrap. And the rule stops
depending on anyone noticing a warning: a check reads the repository's own package manifests,
resolves every build target to its output file, and fails naming both declarations when two
agree.

## Worktree Scope

- **Included:** the test package's target name in `test/qa/Cargo.toml`; the constant every
  test uses to find the Engine (104 occurrences across 37 files today); a reusable target
  audit in `test/qa/src/`; public coverage in `test/qa/tests/t086_single_engine_binary.rs`;
  six private lane checks.
- **Excluded:** any Engine behavior. Routing, guards, locking, minting, receipts, and exit
  codes are not touched, and no test's meaning changes — only the name of the file it
  launches. The private lane crates under `.arca-private/` are separate workspaces with their
  own build outputs; they are read by the audit, never renamed by this ticket.
- **Cross-Feature:** the hold barrier check in `test/qa/tests/t050_blocked_route.rs` is the
  direct witness of the defect, so it must pass from a whole-repository run, not only from a
  package-scoped one.

## Merge Gate

- **Dependencies:** none. This ticket is what releases the held `t-085`.
- **Ticket tests:** `DEBV-001` and `DEBV-004` red first — no target audit exists. `DEBV-002`
  and `DEBV-003` red first because nothing today names which build a test launched.
- **Hidden manifest:** `HT-086-01` through `HT-086-06` cover all six required lanes.
- **Quality and closure:** the whole suite plus workspace quality gates pass in one command —
  which is this ticket's own subject — with no collision warning in the build output;
  `landed-commit` stays empty until the green ticket landing is merged.
