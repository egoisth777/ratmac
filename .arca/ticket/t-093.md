# Ticket: t-093 — The stage has one answer

## Vertical Outcome

"Where are we" has a single owner. While a sprint Run is live, the addressed report names the
cycle stage, because the stage is the State. The tree-derived lookup a person performs today is
labelled a no-live-Run fallback and applies only to the window between sprints, so the two can
never give competing answers.

## Worktree Scope

- **Included:** the structural proof that the cycle machine has exactly one initial State and
  exactly one terminal rest State, so the sprint has one entry and one end; and the working
  rules and orientation prose in `.arca/index.md` that present the lookup as the answer, which
  become the labelled fallback. QA coverage in `test/qa/tests/t093_stage_answer.rs` and six
  private lane checks.
- **Why now:** the demotion is only honest once a Run of the cycle can be started, which is
  what `t-092` delivers; demoting it earlier would leave the question unanswered.
- **Excluded:** the report's rendering is not redesigned — it already prints State and Status
  for an addressed Run, and this ticket adds no field to it. No new command is added.
- **Expected merge/output:** with a live Run the report names the stage; with none, the working
  rules point at the fallback and say so in the same sentence.
- **Superseded-test fate:** none superseded. Any test that asserted the lookup's wording is
  updated to assert the fallback label as well, so the demotion is proven and not merely
  described.
