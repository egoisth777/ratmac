# Ticket: t-106 - Every gap-record citation resolves against the repository, and rot is named

## Vertical Outcome

The working rules state the stamp-landing order - the green landing merges to
`main` first, then a stamp landing flips the record `satisfied` and derives its
`implementation-revision` from the commit the landed tip resolves to at that
moment, never from memory or prediction - and a qa-crate checker resolves every
`git:` citation in every gap record's `implementation-revision`, active folder
and archive counted as one namespace, refusing a record whose cited commit is
unreachable from the repository's refs; a hash that answers `git cat-file` only
as a dangling object is exactly this refusal, not a pass. Reachability binds any
ref, so a record citing a tagged edition commit passes. Byte-frozen history
rides an enumerated allowlist whose rows name record, unresolvable hash, and
reason, and a row that matches nothing fails as stale; post-rule records get no
allowlist path. A rewritten citation is re-pointed by one stamp step that
re-derives the record's citation and the owning ticket's `landed-commit` from
the repository in the same change, and the residual archive move refuses a
record citing a commit that does not resolve and is not allowlisted.

## Worktree Scope

- **Included:** the schema.md Units-and-git revision carrying the stamp-landing
  order as working-rules text (`RCR-001`, the record-side twin of `ELR-001`);
  the citation checker in `ratmac_qa` - parse `implementation-revision`, resolve
  each `git:` hash against refs, refuse unreachable citations naming the record
  and the hash; the enumerated historical allowlist seeded with the eleven
  rotted citations found at filing (res-116/117, res-124/125, res-147..153);
  the residual archive-move refusal consuming the same check; the re-point stamp
  step as a qa-crate routine deriving record and ticket hashes from the
  repository in one change, never from memory; focused tests; six hidden lane
  checks.
- **Excluded:** any Engine `record_contract` change - ADR-0019 keeps the engine
  gate generic over parseable citations; the turn verbs that mechanize the stamp
  inside a close (t-107); rewriting any archived record - frozen bytes ride the
  allowlist, never an edit.
- **Why now:** `implementation-revision` is write-only today - the eleven
  rotted citations pass every machine check (res-159) - and the close t-107
  mechanizes the stamp-landing order this ticket fixes, so the rule
  must enter the working authority first (route edges 1 and 2).
