# Ticket: t-040 — Bounded refusal diagnostics for command guards

## Vertical Outcome

A refused `command_exit` guard prints program identity, expected-versus-observed exit facts, and a bounded stderr diagnostic that names the artifact to repair, with a deterministic 4096-byte bound, an explicit truncation marker, and fixed `no diagnostic emitted` wording for silent commands.

## Worktree Scope

- **Included:** replacing null stdio with bounded capture in `evaluate_command_exit`; extending `GuardFailure` with the diagnostic field and its rendering; documenting the bound.
- **Excluded:** pin verification, freeze, and any other guard kind.
- **Expected merge/output:** refusals that name the concrete repair target, unchanged in every other respect.
