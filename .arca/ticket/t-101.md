# Ticket: t-101 — The engine pin carries its channel

## Vertical Outcome

The Stable Engine pin answers "which edition am I" and the bootstrap resolves stable
against the editions ledger, so a Run judging a landing can be driven by a proven
binary instead of the tree under judgment. Provenance mismatch refuses exactly as an
identity mismatch does; `rtm doctor` names the running engine's channel and flags a
live Run driven off-pin.

## Worktree Scope

- **Included:** the `[engine]` record in `src/pin.rs` gains `source-commit` and
  `channel` fields with the identity's refusal rule; the `ORS-002` bootstrap gains a
  channel argument resolving `stable` from `.arca/editions.md` and `nightly` from the
  current landing, offline; `rtm doctor` gains one channel/provenance row and one
  live-Run mismatch finding. Plus six private lane checks.
- **Excluded:** any hard start-refusal on channel mismatch (a later ask by design);
  publishing or release naming; any change to how editions are cut or audited.
- **Why now:** every self-hosted cycle until this lands is graded by the engine it
  is changing.
