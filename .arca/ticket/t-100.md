# Ticket: t-100 — Every contract gate runs against this repository as it stands

## Vertical Outcome

The stalled Run stops being the only check that ever ran a gate on real history: each contract gate
gets one check that runs it against this repository with a recorded expected verdict, so the checks
keep reporting as this repository's past grows - the pattern `EDNV-004` already proves for tags.

## Worktree Scope

- **Included:** one this-repository check per contract gate - intake, completion, and
  sensitivity-receipt - beside the `ARFV-004` record-contract check `t-097` lands; each states its
  expected verdict in the check and is an oracle, not a snapshot. Plus six private lane checks.
- **Excluded:** any fixture building - these checks address the repository itself; any gate verdict
  change.
- **Why now:** this repository is the one fixture whose history is guaranteed to keep growing, and
  it is free.
- **Note:** the completion and sensitivity gates address a run; the check addresses the most recent
  retired run's receipts, and states the expected verdict for a repository between sprints.
