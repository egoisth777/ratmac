# Ticket: t-117 — descriptive run roster

## Vertical Outcome

Human-facing Run roster output identifies every canonical address together with its recorded top-level or child role, parent and class for children, recorded binding values when present, and State and lifecycle status when readable. Retired or unreadable records are labeled explicitly rather than silently omitted or guessed. Ordering is stable, metadata comes only from Engine-owned records, and a missing address still refuses instead of implicitly selecting a Run. Listing is read-only and needs no current runbook parse, guard evaluation, or pin rewrite.

## Observable Output

Defined before implementation. The public checks and the private lanes both judge this shape; neither needs the other's arrangement or the source.

Every diagnostic that prints the roster keeps its existing first line (the one change: a name that is not plain is quoted in the summary, per **Rendering** below), which still carries the summary `runs: <entry>, <entry>` (or `runs: none (.ratmac/runs/ lists no run; rtm start mints one)`, or `runs: unreadable (<path>: <reason>)` when `.ratmac/runs/` exists but cannot be listed). These are `status`, `step`, `hold`, `spawn`, `abandon`, and `respawn` refusing a missing, empty, or unknown `--run`; `status`, `step`, and `abandon` refusing a repeated one; and every invalid-address refusal. No refusal is added or removed: a command that accepts an input today still accepts it. One row per entry follows, each on its own line and before any `next:` line:

```text
rtm: status: run addressing is always required — pass --run <id>; runs: run-001, run-002, run-003
  run-001: top-level; state delegate; status planned
  run-002: child of run-001; class reviewer; bind ticket="t-7"; state review; status planned
  run-003: child of run-001; class reviewer; bind ticket="t-9"; retired
next: rtm status --run run-001
```

- **Row:** two spaces, the entry, `: `, then fields joined by `; `. The summary lists `.ratmac/runs/` directories only; the rows cover those plus every child a spawn ledger records, one row per distinct name, all sorted by name bytes.
- **Role:** `top-level` only when every spawn ledger on the roster reads cleanly and none records the Run. A recorded child reads `child of <parent>; class <class>`, then `bind <name>=<value>` (several joined by `, `, in name order) when the ledger records bindings, then `supersedes <id>` when recorded. With no readable ledger recording it and at least one ledger unreadable: `role unknown (unreadable spawn ledger <path>: <reason>)`, one clause per unreadable ledger joined by `, `. Recorded by more than one ledger: `role unknown (recorded as a child by <parent>, <parent>)`, parents in name order.
- **Record:** a Run Record that parses gives `state <state>; status <status>`, followed by `; marked abandoned in its parent's spawn ledger` when that mark is set while the record remains. An absent Run Record reads `retired` when retirement is recorded (the transition log's abandonment event for that Run, or the ledger's abandoned mark); `Run Record missing (<path> is absent and no retirement is recorded)` when not; `Run Record absent (retirement unknown: transition log <path> is unreadable: <reason>)` when the log cannot be read. A record that cannot be read or parsed reads `Run Record unreadable (<path>: <reason>)`.
- **Other entries:** a directory under `.ratmac/runs/` that is not a canonical address reads `<name>: not a canonical run address; not addressable`. A child a ledger records with no roster directory reads its role fields, then `not on the roster (<path> is absent)`.
- **Rendering:** a roster entry name (in the summary and in its row), parent, class, State, or binding name is bare when non-empty and made only of ASCII letters, digits, `.`, `_`, and `-`; otherwise it is quoted. Binding values and reasons are always quoted. Quoted means Rust debug quoting: double quotes, with `"`, `\`, and control characters escaped (`\n`, `\r`, `\t`, `\u{1b}`). Paths are absolute under the resolved Engine root, with forward slashes and control characters escaped. No rendered value holds a raw control character, so no stored value can end a row or start one.
- **Sources:** the rows read only `.ratmac/runs/<id>/run.toml`, the roster's `spawn-ledger` files, and the transition log `.ratmac/log.md`, each once. They never read the runbook, run a guard, or write anything. The checks every run command already runs first stay as they are, and so does the `next:` line: a leftover-file refusal still comes first with its own first line, and a changed, broken, or missing runbook never stops the rows.
- **Doctor:** `rtm doctor` keeps its `Run Record:` lines. An absent record reads `(absent — run <id> is retired)` only when retirement is recorded; otherwise `(absent — no retirement is recorded for run <id>)`, or `(absent — retirement unknown: transition log <path> is unreadable: <reason>)`.
