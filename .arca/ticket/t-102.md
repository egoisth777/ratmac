# Ticket: t-102 - The stable bootstrap resolves from the current record and builds a clean tagged tree

## Vertical Outcome

`pwsh -File tools/rtm.ps1 -Channel stable`, invoked from a healthy main, verifies
ledger/tag agreement in the invoking checkout, then locates or builds the engine
from the tagged commit in a clean separate checkout whose tree is identical to that
commit - no hand edit, no overlay, ever. The 2026-08-21 stable-bootstrap wish is
fulfilled and leaves the wishlist in this ticket's green landing.

## Worktree Scope

- **Included:** the resolve/build split in `tools/rtm.ps1` (resolve in the invoking
  checkout; build in a linked worktree at the tagged commit; tree-identity check
  before stamping); Rust fixture tests driving the script over fixture
  repositories; six hidden lane checks; the fulfilled wish leaves the wishlist.
- **Excluded:** any change to edition cutting, the audit, the close guard, or the
  engine's runtime ledger reads (`src/channel.rs` already reads the invoking root).
- **Why now:** until this lands, no future sprint can build its stable driver from
  a tagged commit whose ledger row landed after it - which `ELR-001` makes the
  permanent shape.
