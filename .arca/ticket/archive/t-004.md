# Ticket: t-004 — Consume the human-authored ratmac.toml class

## Vertical Outcome

With a human-provided `.arca/ratmac.toml`, the scheduler recognizes the canonical TOML Machine Class file and consumes it as reviewed input; it offers no agent-authored class-generation path and does not replace the class while running.

## Worktree Scope

- **Included:** canonical `ratmac.toml` discovery/loading and the ownership boundary that treats the TOML class as human-authored, reviewed input.
- **Excluded:** schema details beyond t-003, runtime class immutability/Run instantiation (t-009/t-010), State Files, logs, locks, and transition guards.
- **Expected merge/output:** a human-supplied TOML class is consumed from `.arca/ratmac.toml` without scheduler-authored replacement, with `PT-004-01` green.
