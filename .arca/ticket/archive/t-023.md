# t-023 — Arbitrate concurrent Run access

## Vertical Outcome

Two concurrent `schd` invocations targeting the same Run are serialized by `.arca/schd.lock`; neither can interleave writes, and the resulting state and log remain consistent.

## Worktree Scope

**Included:** Implement per-Run lock acquisition and mutual exclusion across concurrent invocations, plus the concurrency fixture/test.

**Excluded:** Run creation policy, transition-log record format, and multi-Run data-model extensions owned by dependencies or later work.

**Expected merge/output:** A focused lockfile implementation with deterministic concurrent-process coverage showing serialized access and consistent artifacts.
