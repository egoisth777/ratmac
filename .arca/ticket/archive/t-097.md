# Ticket: t-097 — The re-judgment path is proven on an aged fixture

## Vertical Outcome

A stale claim cannot hide behind the archive. On a repository with real history, a requirement
re-judged from an archived record refuses until that record is back in the active folder, a
`satisfied` claim resting on an unmechanized requirement still refuses, and the aged fixture that
proves it is a reusable builder any gate check can compose.

## Worktree Scope

- **Included:** an aged-fixture builder in the QA harness (`test/qa/src/`) that advances a fixture
  tree through a second freeze - records judged at freeze A, archived, goal moved, live records at
  freeze B; the `ARFV-003` re-judgment cases in `test/qa/tests/t048_contract_gates.rs`; the
  `ARFV-004` check running the record gate against this repository as it stands with a recorded
  expected verdict; plus six private lane checks.
- **Excluded:** aged fixtures for the intake contract, completion gate, and sensitivity-receipt
  gate - that sweep is `t-098`; the Merge Gate rule - `t-099`.
- **Why now:** run-002 died on this gate and the bootstrap fix landed with only the pass and
  citation cases; the refusal half of `ARF-002` has never been observed on a fixture with a past.
