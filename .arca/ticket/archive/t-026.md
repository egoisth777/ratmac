# t-026 — Provide print-first status and step output

## Vertical Outcome

`schd status` prints the current Phase Prompt without changing anything; a successful `schd step` prints the current Phase Prompt to stdout and does not spawn a process.

## Worktree Scope

**Included:** Implement print-first status and successful-step stdout behavior, including requirement-specific R-030 status and T-16 successful-step checks with no-process-management execution.

**Excluded:** Prompt composition and phase-scope rules, parser validation, and transition semantics owned by dependencies.

**Expected merge/output:** A focused Rust CLI output path with deterministic status and successful-step tests that observe stdout and filesystem/process effects.
