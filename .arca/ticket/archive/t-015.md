# Ticket: t-015 — Hard-fail corrupt State File

## Vertical Outcome
When `.arca/state.toml` is corrupt, `schd` halts with an actionable parse report and performs no guessed state update or transition.

## Worktree Scope
- **Included:** Strict State File parse/error path, actionable report, and guarantee that corrupt input cannot mutate or advance the Run.
- **Excluded:** State schema/ownership (t-007), class parsing, and ordinary transition refusal.
- **Expected merge/output:** The parser and `T-14` integration test merge after t-007; corrupt-state handling remains a hard error in every command that reads state.
