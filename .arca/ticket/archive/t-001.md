# Ticket: t-001 — Make Phase the sole machine-state dimension

## Vertical Outcome

Given a valid Machine Class and a Run, the scheduler can expose and advance the Run's machine position using `phase` alone; lifecycle `status` is not a second graph dimension and cannot create an alternate machine state.

## Worktree Scope

- **Included:** the machine-state model, phase-based transition lookup, and the focused Rust proof that status is not part of the machine graph.
- **Excluded:** status lifecycle semantics (t-002), Machine Class parsing (t-003/t-005), CLI/run persistence, guards, and filesystem layout.
- **Expected merge/output:** a minimal Phase-only state model and green `PT-001-01`; no unrelated CLI or file-format behavior.
