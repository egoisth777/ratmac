# t-029 — Document user-only start policy

## Vertical Outcome

The CLI help and executable workflow documentation state that `schd start` is user-only and loop entry is never agent-initiated; this policy is explicit without pretending to authenticate callers, as required by ADR-0003.

## Worktree Scope

**Included:** Add the policy to the user-facing `schd start --help`/workflow help surface and test that the documented rule is present and unambiguous.

**Excluded:** Caller authentication or identity enforcement (intentionally not code-enforced in ADR-0003), transition guard logic, and `schd step` caller policy owned by t-030.

**Expected merge/output:** A focused help/documentation change with an executable CLI/help proof for the documented user-only start rule, without an authentication shim.
