# Ticket: t-007 — Define and report the Scheduler State File

## Vertical Outcome

The Scheduler can create and report `.arca/state.toml` with exactly the required machine position, lifecycle, revision, reference, and blocker fields; `status`, `blocker`, and pending guards are visible through `schd status` without changing state.

## Worktree Scope

- **Included:** the State File schema and serialization for `phase`, `status`, `goal_revision`, `input_revision`, `output_revision`, `active_refs`, and `blocker`, plus read-only status reporting.
- **Excluded:** sole-writer enforcement (t-008), corrupt-state refusal (t-022), Run instantiation (t-010), transition logging/locking, and unrelated CLI commands.
- **Expected merge/output:** valid State Files round-trip with all required fields and `schd status` prints the current state and pending guards without mutation; `PT-007-01`, `T-07`, and `T-15` are green.
