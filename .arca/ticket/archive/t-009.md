# Ticket: t-009 — Keep ratmac.toml a pure read-only Machine Class

## Vertical Outcome

`schd start` reads `.arca/ratmac.toml` as an immutable class template and uses it to begin a Run without adding runtime state to the class file or changing its bytes.

## Worktree Scope

- **Included:** immutable Machine Class loading and the runtime boundary that keeps class data separate from Run state; the R-013 ownership of source T-19.
- **Excluded:** strict schema parsing (t-005), State File schema/writes (t-007/t-008), Run artifact creation details (t-010), active-run limits, locks, and transitions.
- **Expected merge/output:** class bytes and class representation remain read-only across `schd start`; goal `T-19` is green and Run-specific state is kept outside `ratmac.toml`.
