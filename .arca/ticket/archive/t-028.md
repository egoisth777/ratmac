# t-028 — Run arbitrary Machine Classes

## Vertical Outcome

The engine runs a valid Machine Class unrelated to wishwillow's P1–P5 names with the same parse, transition, state, and prompt behavior; no project-specific knowledge is required.

## Worktree Scope

**Included:** Remove or prevent wishwillow-specific assumptions in the generic class/run path and add a non-wishwillow end-to-end fixture test.

**Excluded:** Machine Class grammar, prompt print-first dispatch, and wishwillow documentation; those are defined by dependencies or outside this requirement.

**Expected merge/output:** A focused generic engine path and fixture proving an independently named class can start, status, and step identically.
