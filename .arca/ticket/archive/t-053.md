# Ticket: t-053 — Project-local bootstrap and read-only doctor

## Vertical Outcome

One documented command run from the project root resolves or builds the Stable Engine binary, reports its path and SHA-256, refuses on pin mismatch, and touches no global configuration, PATH, or network; `rtm doctor` reports Engine identity, Runbook presence and validity, and runtime state, names the next legitimate action when no Run exists, and provably writes nothing.

## Worktree Scope

- **Included:** the bootstrap entry point, its pin comparison against the t-041 pin record, doctor output content, and the zero-write proof.
- **Excluded:** caller-policy wording (t-043) and behavioral role scenarios (t-044).
- **Expected merge/output:** a fresh session can orient and start without ad-hoc installation.
