# Ticket: t-010 — Instantiate a Run with its owned artifacts

## Vertical Outcome

`schd start` instantiates a Run from the read-only Machine Class, persists the Run-owned State File and append-only Transition Log, and returns a Run/artifact descriptor for the exact `.arca/schd.lock` path. The invocation lock is released (and absent) when `start` returns, while `ratmac.toml` remains untouched.

## Worktree Scope

- **Included:** Run instantiation from a class, creation/ownership of the persistent State File and Transition Log, the Run-owned lock-path descriptor and release-on-return behavior, and the requirement-specific R-014 proof derived from source T-19.
- **Excluded:** class parsing/immutability (t-004/t-005/t-009), active-Run limit, concurrent lock arbitration, transition behavior, and State File field design.
- **Expected merge/output:** one `Scheduler::open(...).start() -> Run` creates persistent `state.toml` and `log.md` at the flat `.arca` layout, returns ownership metadata naming `.arca/schd.lock` (with no lock left after return), and preserves the class; `PT-010-01` is green.
