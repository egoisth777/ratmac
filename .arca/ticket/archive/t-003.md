# Ticket: t-003 — Restrict Machine Class declarations to phases and transitions

## Vertical Outcome

Loading `ratmac.toml` accepts a Machine Class that declares Phases and transitions only; a declaration of a `status` dimension is rejected rather than becoming machine state.

## Worktree Scope

- **Included:** the Machine Class schema boundary needed to accept phase/transition declarations and reject a status dimension, with the source T-13 proof.
- **Excluded:** general unknown-key diagnostics (t-005), state-file status handling (t-002/t-007), guards, Runs, and CLI lifecycle.
- **Expected merge/output:** a parseable phase/transition class model with status-free declarations and green `T-13`; no runtime state persisted in the class.
