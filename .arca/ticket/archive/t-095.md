# Ticket: t-095 — Every edition obeys the convention

## Vertical Outcome

An edition that was cut wrong is found by a check rather than by a person following a citation.
An audit over this repository's own tags reports, by name, any edition that is not annotated,
whose message does not record the bar, or whose commit is not reachable from the trunk. It keeps
reporting as editions accumulate, because it reads the repository as it stands rather than a
frozen list.

## Worktree Scope

- **Included:** an audit in `test/qa/tests/t095_edition_audit.rs` reading every `edition-*` tag in
  the repository under test, plus six private lane checks. The audit names the offending tag and
  what was wrong with it.
- **Why now:** `edition-001` already exists and nothing reads it; the longer editions accumulate
  unchecked, the more citations rest on marks nobody verified.
- **Excluded:** the audit does not re-run the gates the bar names - it cannot, at a commit it is
  not standing on - and it never creates, moves, or deletes a tag. Whether the sequence has holes
  is `t-096`'s subject, not this one's.
- **Expected merge/output:** the audit passes on this repository as it stands, and fails by name if
  a lightweight or undocumented edition is introduced.
- **Superseded-test fate:** none superseded.
