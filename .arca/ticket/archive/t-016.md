# Ticket: t-016 — Deterministic transition requests

## Vertical Outcome
An agent's `schd step` request is evaluated by Exit Guards: a request with passing artifact guards advances the Phase, while a request with a failing guard is refused regardless of the agent's claim.

## Worktree Scope
- **Included:** `schd step` request handling and deterministic guard-gated accept/refuse decision; wire the passing path to the next Phase.
- **Excluded:** Guard fact collection details (t-017), refusal-state immutability/reporting (t-018–t-020), and caller policy.
- **Expected merge/output:** Request orchestration and the two requirement-specific tests merge after t-003/t-010; no claim field can bypass guard evaluation.
