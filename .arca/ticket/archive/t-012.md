# Ticket: t-012 — Refuse a second active Run

## Vertical Outcome
When one Run is active for a project, a second `schd start` is refused with an actionable result and the existing active Run remains unchanged.

## Worktree Scope
- **Included:** v1 active-Run admission check and refusal path for `schd start`, including the state/lock inspection needed to preserve the existing Run.
- **Excluded:** N-Run data representation (t-011), run-id arguments (t-013), and guard evaluation.
- **Expected merge/output:** The CLI behavior and `T-08` integration test merge on top of t-011 and preserve the active Run's files and identity on refusal.
