# Ticket: t-049 — Safe human-authorized Run abandonment

## Vertical Outcome

`rtm abandon` requires explicit human authorization, checks it before the first write, records a terminal abandoned event in the Scheduler-owned log, marks the State File terminal, and retires the lock so a fresh Run can start; unauthorized requests refuse atomically with state, log, and lock byte-identical, and a stale lock is retired only through this path.

## Worktree Scope

- **Included:** the abandon command, its authorization phrase, terminal event, lock retirement, and stale-lock recovery.
- **Excluded:** the blocked route (t-048).
- **Expected merge/output:** a mechanized exit from a broken Run that no agent edit can substitute for.
