# t-024 — Render phase prose with generated guards

## Vertical Outcome

A Phase's prompt is printed as its short inline `ratmac.toml` prose followed by the mechanically generated list of that Phase's Exit Guards.

## Worktree Scope

**Included:** Implement prompt rendering from the phase `prompt` field and guard definitions, with the owned end-to-end stdout check.

**Excluded:** Guard pass/fail execution, phase selection, comment filtering, and exclusion of other phases/graph content beyond the prompt contract.

**Expected merge/output:** A focused Rust renderer wired to the Scheduler output path, with deterministic fixture-driven prompt ordering and content coverage.
