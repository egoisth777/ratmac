# Ticket: t-017 — Artifact-based Exit Guards

## Vertical Outcome
Exit Guards decide from observable artifacts—filesystem shape, file content, and command exit code—so changing only an agent's completion claim cannot turn a failing check into a pass.

## Worktree Scope
- **Included:** Guard evaluators for exact filesystem/file-content facts and command exit status, plus their integration into `schd step`.
- **Excluded:** Request orchestration (t-016), refusal immutability/report text (t-018–t-020), and policy-only caller rules.
- **Expected merge/output:** Artifact evaluators and `PT-017-01` merge after t-003/t-016; no evaluator reads an agent claim as proof.
