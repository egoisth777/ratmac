# Ticket: t-008 — Enforce Scheduler-only State File writes

## Vertical Outcome

Across scheduler invocations and direct agent/worktree attempts, only `schd` changes `.arca/state.toml`; a read-only status operation and an agent-side access leave its bytes unchanged, while a Scheduler transition is the only permitted mutation.

## Worktree Scope

- **Included:** the State File write boundary, Scheduler-owned mutation path, and the proof that non-Scheduler command paths cannot write state.
- **Excluded:** State File field/schema design (t-007), corrupt-state handling, lock arbitration, Run lifecycle, and transition semantics.
- **Expected merge/output:** all state mutations flow through Scheduler code and the sole-writer contract is proven by `PT-008-01`; t-007 reporting remains intact.
