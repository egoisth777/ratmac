# Ticket: t-039 — Reviewable snapshots and honest acceptance oracles

## Vertical Outcome

`cargo test --workspace` is green on this branch with pending contributor artifacts present; the history oracle treats a complete authorized archive move as preservation and still fails on mutation or partial moves; evidence recording emits a verifiable snapshot manifest and refuses undeclared untracked content; the release lane runs only under `RATMAC_RELEASE_ACCEPTANCE=1` and reports its skip.

## Worktree Scope

- **Included:** fixing the draft snapshot audit so it compiles and is tracked; manifest emission and untracked refusal; archive-aware history oracle with mutation/partial-move negatives; opt-in release lane plus visible skip reporting; `.arca/index.md` archive-authorization and reviewable-snapshot rules; documenting the opt-in in the QA test list.
- **Excluded:** engine changes of any kind; pin, receipt, gate, bootstrap, or trial work.
- **Expected merge/output:** a green default suite and committed schema rules that later tickets can rely on.
