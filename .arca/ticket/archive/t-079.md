# Ticket: t-079 — One spelling for the reported Engine root

## Vertical Outcome

Every rendered Engine-root path leaves the Engine in one spelling: forward slashes, no
platform separator mixed in, the same on the Git route and the no-Git fallback, and the
same in the human report and the JSON report. The resolved value does not change; only
its rendering does. A reader comparing `rtm status` and `rtm doctor --json` sees the same
characters, and the report matches the thirteen other paths `src/` already normalizes.

## Worktree Scope

- **Included:** one owned renderer for a displayed path; its use at the three sites that
  print an Engine root (`src/scheduler.rs` human status, `src/doctor.rs` human report,
  `src/doctor.rs` JSON member); public coverage in
  `test/qa/tests/t079_root_spelling.rs`; six private lane checks.
- **Excluded:** the resolver itself (`Roots::resolve` keeps returning a real `PathBuf`),
  path comparison anywhere in the Engine, refusal text, and every other report line. No
  new option, no new state, no filesystem change.
- **Cross-Feature:** the linked-worktree, no-Git, and path-addressed doctor routes keep
  reporting the same root they report today, spelled the new way.

## Merge Gate

- **Dependencies:** `t-078` is green and merged.
- **Ticket tests:** `ENSV-011` gains a spelling assertion that reds against current source.
- **Hidden manifest:** `HT-079-01` through `HT-079-06` cover all six required lanes.
- **Quality and closure:** affected suites plus workspace quality gates pass;
  `landed-commit` remains empty until the green ticket landing is merged.
