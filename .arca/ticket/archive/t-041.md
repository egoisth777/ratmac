# Ticket: t-041 — Pinned gate execution boundary

## Vertical Outcome

Guard evaluation executes only pinned or explicitly exempt programs: the resolved path and SHA-256 of every project-derived gate artifact are recorded in Run evidence no later than first guard use and re-verified at each evaluation, tamper is refused with observed and expected identity, and a guard that would rebuild the workspace is rejected at validation or pin time.

## Worktree Scope

- **Included:** pin recording in Run evidence; per-evaluation re-hash and refusal; exempt-probe marking in the Runbook; rejection of build-at-evaluation guard commands.
- **Excluded:** diagnostics (t-040), freeze (t-042), and receipts (t-045).
- **Expected merge/output:** a hash-verified, build-free guard boundary.
