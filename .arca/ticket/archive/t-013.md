# Ticket: t-013 — Active Run targeting without run-id

## Vertical Outcome
In v1, `schd step` and `schd status` operate on the active Run using no run-id argument; supplying a run-id is rejected rather than selecting a different Run.

## Worktree Scope
- **Included:** CLI argument shape and active-Run lookup for `schd step` and `schd status`, with rejection of run-id forms.
- **Excluded:** Run storage/cardinality (t-011), one-active admission (t-012), and transition guard semantics.
- **Expected merge/output:** The two command paths and `T-09` integration test merge after t-011/t-012 and target the same active Run deterministically.
