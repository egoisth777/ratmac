# t-021 — Make refused step idempotent

## Vertical Outcome

When a failing Exit Guard is retried any number of times, `schd step` emits the same refusal result and leaves the Run's Phase, Status, counter state, and Transition Log unchanged each time.

## Worktree Scope

**Included:** Implement failure-path idempotence for `schd step`; preserve the ADR-0006 refusal report while making repeated attempts observationally identical; add the owned public test and fixture.

**Excluded:** Exit-Guard definitions and refusal semantics owned by predecessor tickets; successful transitions, lock arbitration, and unrelated CLI behavior.

**Expected merge/output:** A focused Rust implementation and test change that makes repeated failing steps deterministic without adding a retry counter or refusal log mutation.
