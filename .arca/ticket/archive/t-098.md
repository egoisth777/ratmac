# Ticket: t-098 — Every contract gate is exercised on a fixture with a past

## Vertical Outcome

No contract gate can be unpassable on real history while the suite is green. The intake contract,
the completion gate, and the sensitivity-receipt gate each gain at least one check on a fixture
carrying the kind of history that gate walks, with the expected verdict stated - the coverage whose
absence let the record contract stay broken for months.

## Worktree Scope

- **Included:** one fixture-with-a-past check per remaining contract gate: the intake contract on a
  tree with archived issue bundles and archived tickets from an earlier freeze; the completion gate
  and the sensitivity-receipt gate on a tree carrying receipts from an earlier, retired run beside
  the addressed run's own. Each composes the `t-097` aged-fixture builder. Plus six private lane
  checks.
- **Excluded:** any change to a gate's verdict - this ticket adds coverage, never behavior; the
  Merge Gate rule (`t-099`); the this-repository checks (`t-100`).
- **Why now:** `t-097` lands the builder; every day a gate lacks an aged check is a day the
  run-002 defect class can return unseen.
