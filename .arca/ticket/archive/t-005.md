# Ticket: t-005 — Reject unknown ratmac.toml keys strictly

## Vertical Outcome

A malformed `ratmac.toml`, including one containing any unknown key, halts class loading with an actionable hard error; the scheduler never ignores or guesses around the unknown input.

## Worktree Scope

- **Included:** strict TOML deserialization for the Machine Class and actionable unknown-key/parse-error reporting, including the R-011 portion of source T-13.
- **Excluded:** the Phase/status model (t-001/t-002), class ownership/naming (t-004), state-file parsing, guards, and Run lifecycle.
- **Expected merge/output:** malformed or unknown-key classes fail deterministically without partial scheduler state, while valid classes still load; `T-12` and `PT-005-02` are green.
