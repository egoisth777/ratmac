# Ticket: t-099 — The Merge Gate demands the fixture with a past

## Vertical Outcome

The coverage `t-097` and `t-098` land cannot decay: the working rules' Merge Gate contents require a
ticket that adds or amends a contract gate to list its fixture-with-a-past check, the same way
hidden-lane coverage is listed, and a check proves the rule is written where review reads it.

## Worktree Scope

- **Included:** the one-sentence rule in the working rules' Merge Gate section; a check in the QA
  suite proving the section carries it (the same pattern that pins other schema sentences the suite
  relies on); the retrofit listing in this sprint's own tickets is already written. Plus six private
  lane checks.
- **Excluded:** any mechanized scan of test code for coverage - rejected in the issue design; the
  binding point is review.
- **Why now:** rules that land after the sweep they protect are the ones that never land.
