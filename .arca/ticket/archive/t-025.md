# t-025 — Keep prompts phase-scoped

## Vertical Outcome

The machine information delivered in a Phase Prompt contains only that Phase's prompt and generated guards; it never exposes the flowchart or another Phase.

## Worktree Scope

**Included:** Enforce phase-scoped prompt selection/output and add the owned boundary test.

**Excluded:** Prompt prose/guard rendering mechanics, comment handling, and CLI status/step dispatch outside the information boundary.

**Expected merge/output:** A focused Rust prompt-scope implementation and fixture test proving neither other phases nor the machine graph leak into output.
