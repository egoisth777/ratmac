# Ticket: t-094 — The cycle cannot reach rest unmarked

## Vertical Outcome

A sprint that forgets to cut its edition is stopped at the last stage. The closing State of this
repository's Machine Class carries an Exit Guard that passes only when a tag named `edition-*`
points at the commit being left, so every sprint ends on an edition and therefore every sprint
starts from one. The refusal names the command and the observed exit code; nothing is written by a
refused step, and the Engine gains no knowledge of version control.

## Worktree Scope

- **Included:** one `command_exit` guard added to the closing State's guard list in
  `.ratmac/ratmac.toml`, beside the record contract it already carries. Public QA coverage in
  `test/qa/tests/t094_edition_guard.rs` proving the refusal, the pass after tagging, and that a
  refusal writes nothing, plus six private lane checks.
- **Why now:** the rule landed as prose at P1 and prose is what this shop converts into checks;
  until the guard exists, the marker depends on somebody remembering, which is the failure the
  issue was filed about.
- **Excluded:** no new guard kind, no engine source change, no automation that cuts the tag. The
  bar in `EDN-001` is proven by the gates the cycle already runs before the closing State is
  reachable; this ticket proves only that the mark is present.
- **Expected merge/output:** the runbook declares the guard, `rtm doctor` still exits `0` on this
  repository, and the step into rest refuses until an edition is cut.
- **Superseded-test fate:** none superseded. The existing checks that read the shipped Machine
  Class gain the new guard in their expected shape rather than being replaced.
