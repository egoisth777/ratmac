# Ticket: t-141 — unique test scratch folders

## Vertical Outcome

Every test that makes a scratch folder, in the public suites under `test/qa` and in the declared, non-expired private lanes under `test-hidden`, receives one that no other test can be handed, even when two requests share one clock tick. One shared test-support helper hands out every such folder: it creates the folder new, never adopting, emptying, or deleting an existing one; its names do not rest on the clock alone; and it retries a taken name with a new one. Only the shared-support oracle lane (`t-126`) keeps its own allocator, which puts a counter in each name, creates each folder new, and stops on a taken name instead of retrying. A check pins the helper's clock and proves that two requests get separate folders, so a suite gives the same verdict in parallel as alone.
