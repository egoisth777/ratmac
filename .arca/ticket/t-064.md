# Ticket: t-064 — Composition format extension

## Vertical Outcome

One runbook can declare a composed machine. The format authority and the typed parse gain the
class and spawn tables and the `join` guard kind: a runbook carrying them parses without the
format-restriction refusal and comes back doctor-clean; a malformed declaration refuses with a
stable RB5xx code naming the offending key; `blocked-route` stays the canonical hyphen spelling.
Declarations are inert - no runtime behavior changes, nothing spawns.

## Worktree Scope

- **Included:** `.arca/runbook-spec.md` class/spawn/`join` sections plus the RB5xx defect-class
  rows, `src/machine.rs` typed parse (class table with required binding set RB505 posture, per-
  Phase spawn declarations, `join` in the closed guard vocabulary), `src/doctor.rs` schema pass
  accepting and diagnosing the new tables, `test/qa/tests/t064_composition_format.rs`,
  `.arca-private/t-064/` hidden lanes, `.arca/runbook-authoring.md` notes.
- **Excluded:** any spawn/respawn verb, ledger content, recursion cap, the cycle-termination
  doctor pass (t-067), `scaffold.rs` (the smallest runbook stays minimal and doctor-clean).
- **Expected merge/output:** `MachineClass::from_toml` remains the only schema boundary; the new
  shapes are typed there and nowhere else; tableless runbooks parse byte-identically.
- **Superseded-test fate:** none expected - no existing oracle pins the absence of the tables;
  unknown-key refusal tests stay green because the new keys become known.
