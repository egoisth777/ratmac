# Ticket: t-083 — Every surface a caller reads says State

## Vertical Outcome

Whatever a person or an agent reads out of the Engine names the machine position State.
The prose a position declares, plus its generated guard and input list, is the State
Prompt. The human status report, the human doctor report, the machine-readable doctor
output, refusal text, and Run evidence all say State. The Engine's own identifiers say it
too, so a contributor reading the source and a caller reading a report use one word. The
three names stay separate everywhere: State is the position, Run Record is the file, Run
is the live instance, and `status` keeps its five values and its Engine ownership.

## Worktree Scope

- **Included:** the report renderers and their words (`src/scheduler.rs` human status,
  `src/doctor.rs` human and machine-readable reports, `src/state.rs` rendered record
  summary and the prompt type), refusal text across `src/`, and the remaining Engine
  identifiers for the position. Public coverage in
  `test/qa/tests/t083_state_surfaces.rs`; six private lane checks.
- **Excluded:** the tracked-tree audit that proves the absence repository-wide (`t-084`),
  and anything that changes what a report *says about the world* rather than what it calls
  it. No field is added or removed, no report gains or loses a line.
- **Cross-Feature:** the machine-readable doctor output keeps its member names stable for
  scripted callers except where the row requires the rename, and both the human and
  machine-readable routes report the same position for the same invocation.

## Merge Gate
