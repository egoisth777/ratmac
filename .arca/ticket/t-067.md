# Ticket: t-067 — Cycle termination as a static check

## Vertical Outcome

Termination becomes a static check by guard-kind membership. The doctor gains a termination pass:
every cycle in the transition graph must carry at least one out-edge guarded by a receipt- or
contract-class guard. A guarded-cycle runbook passes with zero termination findings; removing
that guarded edge fails the check, naming the cycle's Phases and the missing guard-kind class.
The check never executes a guard - membership in the closed kind vocabulary is the whole test.

## Worktree Scope

- **Included:** `src/graph.rs` cycle enumeration over ordinary edges, `src/doctor.rs` termination
  pass with its stable finding code and JSON rendering, `.arca/runbook-spec.md` termination-check
  row, `test/qa/tests/t067_cycle_termination.rs`, `.arca-private/t-067/` hidden lanes.
- **Excluded:** guard execution, spawn/join runtime, blocked routes as terminators (hold-only
  routes never satisfy termination), any change to `rtm step` routing.
- **Expected merge/output:** the doctor stays read-only and diagnoses through `machine.rs`; the
  new pass rides the existing findings-as-data pipeline and exit-code mapping.
- **Superseded-test fate:** none expected - no existing fixture contains an unguarded cycle;
  every prior doctor fixture must keep its finding count.
