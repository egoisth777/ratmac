# Ticket: t-080 — The runbook declares States

## Vertical Outcome

A runbook written the settled way parses, passes the doctor clean, and drives a Run from
start to a terminal position: `[states.<name>]` under a top-level `states` table, a
State's children under `[[states.<name>.spawns]]`, and a child class's machine under
`[classes.<name>.states]`. Transition `from` and `to` name States. Every other key, guard
kind, validation rule, and diagnostic code of the format behaves exactly as it does today,
and the Engine's own words for the thing follow the format: the type is a State, the map
is states, the accessor is states.

## Worktree Scope

- **Included:** the runbook parse and the parsed model (`src/machine.rs` top-level and
  child-class maps and the declaration type), the graph type and its accessors
  (`src/graph.rs`), every consumer that reaches declarations through the old accessor
  (`src/contract.rs`, `src/doctor.rs`, `src/scheduler.rs`), and the format's own fixtures
  under `test/qa/fixtures/`. Public coverage in `test/qa/tests/t080_states_table.rs`; six
  private lane checks.
- **Excluded:** the Run Record's filename and fields (`t-081`), refusal of a pre-cutover
  runbook (`t-082`), caller-visible report text (`t-083`), and the live-surface audit
  (`t-084`). No new key, no new guard kind, no new validation rule.
- **Cross-Feature:** composition stays capped at one level and spawn ledgers, join
  contracts, and blocked routes keep resolving the same declarations they resolve today.

## Merge Gate

- **Dependencies:** none; this is the first ticket of the cutover.
- **Ticket tests:** `SVCV-002` reds first against current source, which accepts only the
  pre-cutover table.
- **Inherited red:** `t055_runbook_spec::specification_is_routed_and_states_the_shape` is
  red at the freeze because the documented format moved ahead of the Engine; it turns
  green here and must be green at closure.
- **Hidden manifest:** `HT-080-01` through `HT-080-06` cover all six required lanes.
- **Quality and closure:** affected suites plus workspace quality gates pass, taken with
  `cargo test -p ratmac-qa` until [i-027](../issue/i-027-duplicate-engine-binary/index.md)
  lands; `landed-commit` stays empty until the green ticket landing is merged.
