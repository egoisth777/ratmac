# Ticket: t-104 - The engine writes its own operator skill

## Vertical Outcome

A new `rtm` subcommand writes the thin `ratmac-operator` skill folder at a fresh
path - `SKILL.md` plus references, engine-identity stamp, never overwrites - and
the skill teaches only invariant behavior: orient, read the prompt, place
artifacts, step, branch on refusal codes, never write under the engine root.
Anything version-shaped is reached by running the command, never by quoting it.

## Worktree Scope

- **Included:** the skill subcommand as a sibling of the scaffold (one folder,
  refuse-existing, identity stamp); `SKILL.md` and reference content teaching the
  loop and the never-touch rules with no flag enumeration; a content scan test; six
  hidden lane checks.
- **Excluded:** any MCP surface; any AGENTS.md stub (a later issue if activation
  proves unreliable); any change to the renderers t-103 owns.
- **Why now:** the operator protocol's portable half; depends on t-103 because the
  skill points at the CLI's own output for everything current (sprint route edge 1).
