# Ticket: t-135 — distributable plan build profile

## Vertical Outcome

A distributable Plan-Build profile contains the Machine Class template, executable artifact schemas and validators, issue/gap/work-item blanks, required terms, and operating instructions needed by its guards. A clean repository with no .arca/schema.md and no inherited system prompt can initialize the profile and drive a complete issue-to-proven-completion sprint using only its packaged contract and Engine output. Profile fields and roots are declared data; the Engine gains no project-specific source code. Missing, malformed, or incompatible profile artifacts refuse with actionable guidance. Existing user files are never overwritten silently, and installation is deterministic and offline.

## Worktree Scope

Implement only [the accepted distributable plan build profile issue](../issue/i-046-distributable-plan-build-profile/spec.md).
Existing source boundaries: `src/`, `profiles/plan-build/`, `.arca/index.md`. Add only the directly required module or command wiring where the accepted design calls for it; keep unrelated behavior unchanged. The implementing turn also owns its public suite, private crate, this ticket, its gap record, and the roster entry for its new private crate. Any necessary existing regression adjustment must cite the exact newly accepted contract; never weaken an unrelated assertion.

The main coordinator opens and closes the registered ticket worktree, invokes the Engine, records actual receipts and snapshots, and owns shared authority and history. Agents own disjoint source, public-proof, and private-proof paths assigned at turn start. Review exact source and oracle bytes before expensive private proof. No goal edit is allowed during the frozen build batch.
