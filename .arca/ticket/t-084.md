# Ticket: t-084 — The audit carries history by name, and catches a slip

## Vertical Outcome

One audit walks the whole tracked tree and fails if the pre-cutover spelling of the machine
position appears on any live surface. History is not skipped, it is listed: archived issue
bundles, archived tickets, archived gap records, and the append-only history file are named
in an enumerated allowlist, each row with a reason, and their bytes stay exactly as they
were. The list cannot rot — an entry that no longer matches anything fails the audit — and
it cannot hide a slip: planting the old spelling in a live surface fails the audit there.

## Worktree Scope

- **Included:** the existing live-surface audit and its enumerated allowlist
  (`test/qa/tests/t034_rat005.rs`, `test/qa/fixtures/rebrand-audit/allowlist.tsv`, and the
  acceptance lane that re-reads the same list in `test/qa/tests/t037_rat008.rs`), extended
  to carry the pre-cutover position spelling. Public coverage in
  `test/qa/tests/t084_state_audit.rs`; six private lane checks.
- **Excluded:** renaming anything in the Engine — that is `t-080` through `t-083`, all
  landed before this ticket — and editing any archived bytes, which the row forbids.
- **Cross-Feature:** the audit keeps covering the old brand token it already covers; the
  two token sets share one list and one walk.

## Merge Gate

- **Dependencies:** `t-083` is green and merged, so no live surface should still carry the
  old spelling when this audit is switched on.
- **Ticket tests:** `SVCV-009` reds first — the audit exists but carries no row and no
  assertion for the position spelling.
- **Hidden manifest:** `HT-084-01` through `HT-084-06` cover all six required lanes.
- **Quality and closure:** affected suites plus workspace quality gates pass, taken with
  `cargo test -p ratmac-qa` until [i-027](../issue/i-027-duplicate-engine-binary/index.md)
  lands; `landed-commit` stays empty until the green ticket landing is merged.
