# Ticket: t-076 — Roots table

## Vertical Outcome

A runbook declares repository-relative guard roots in one top-level `[roots]` table, and
all guards address those roots by role name. Static validation gives different diagnostic
codes for an undeclared name, missing path, and Engine-root overlap; Engine source no
longer embeds a `.arca` path literal or workflow-specific filesystem address.

## Worktree Scope

- **Included:** typed `[roots]` parsing and validation; root-name resolution for every guard
  consumer; documented diagnostic codes and doctor rendering; replacement of Engine-source
  `.arca` path literals with the root/resolver model; fixture/runbook updates; QA coverage
  in `test/qa/tests/t076_roots_table.rs`; and six private lane checks.
- **Inherited gap (`res-106`, ENS-001):** `t-071` proved the Engine root and its runtime
  layout but left `blocked::apply_hold` writing `.arca/ticket/<id>.md` (src/blocked.rs:113).
  ENS-001 forbids the Engine writing any file under `.arca/`; its "except through a root"
  exception covers reads only. Root-routing that path is therefore not enough - the write
  must be eliminated: the hold outcome stays in Engine state and the transition log, a
  declared workflow root may READ the ticket, and any ticket-file annotation becomes a
  deterministic shop action or receipt performed by the workflow layer, not the Engine.
  That contradicts `.arca/schema.md` and PGE-006's "an authorized `rtm hold` marks the
  ticket held" mechanics, so a P1 issue must revise them before this ticket implements
  the change. `res-106` also waits on `ENSV-013` in `t-074`, hence the dependency; this
  ticket judges the record only when both clauses are true.
- **Excluded:** Engine-root resolution itself (`t-071`), pre-split residue detection
  (`t-077`), workspace binding (`t-074`), and changes to guard kinds or their existing
  readiness semantics. The table is repository-relative data, not a way to grant arbitrary
  absolute-path access.
- **Expected merge/output:** a valid named root resolves only within the repository, each
  named static defect returns its own stable diagnostic before Engine motion, and an audit
  of `src/` finds no `.arca` literal.
- **Superseded-test fate:** hard-coded workflow-path fixtures are converted to root-name
  fixtures; existing guard pass/refusal behavior remains required after its filesystem
  address is data-driven.
