Two limits are recorded rather than defended, both in the ticket and where a reader
meets them in the source.

A path alias below the Engine root - a hard link standing in for the Engine's own log -
is outside the cooperative threat model. A hard link cannot be told from an ordinary file
by path, and the only complete defence would require the Engine source to name the
contributor history, which `ENS-008` forbids. Anyone able to create one can already write
the contributor history directly.

A process death between the State rename and the append leaves a transition that happened
with no record of it. The ordering is deliberate: the failure is a missing true record and
never a false one, because a history that can lie is worse than one that can have a gap.
`inject_step_fault("after-state-replace")` and the `t062` assertion demonstrate the window.
